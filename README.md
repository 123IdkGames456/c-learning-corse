# C# Academy

A dyslexia-friendly C# learning website with a structured 1,000-course curriculum.

## Curriculum

- 100 chapters
- 10 courses in every chapter
- Course difficulty shown as `###/100`
- Short explanations, large text, and generous line spacing
- Code-reading examples and mixed question formats
- Course pass score: 70%
- Final exam: 30 mixed questions; every answer must be correct to finish
- Failed final exams recommend chapters to practise
- Progress and XP saved in the browser with localStorage

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**.
5. Save and wait for GitHub Pages to publish the site.

The expected site address is:

https://123idkgames456.github.io/c-learning-corse/

Progress is stored in the browser used to access the site. It does not automatically sync between devices.
